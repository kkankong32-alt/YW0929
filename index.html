1. Storybook 한 번에 만들기

상황

교과서 PDF를 올린 뒤 첫 그림동화를 생성할 때

프롬프트
첨부한 초등학교 3학년 사회 교과서 자료를 바탕으로
수업 도입에 사용할 storybook을 만들어 줘.

[수업 주제]
교통의 변화로 달라진 사람들의 생활 모습

[대상]
초등학교 3학년

[목적]
개념을 설명하는 학습 만화가 아니라,
수업을 시작할 때 학생들의 호기심을 일으키는 짧은 이야기로 만들어 줘.

[이야기]
옛날에 살던 어린이 '도윤'과
오늘날에 사는 어린이 '하린'이
각자의 시대에서 먼 곳에 있는 같은 목적지로 떠난다.

두 어린이가 이동하는 모습을 번갈아 보여 주면서
옛날과 오늘날의 교통수단과 이동 모습이 자연스럽게 비교되도록 해 줘.

첨부한 교과서에 제시된 내용과 어긋나는 사실은 넣지 말고,
초등학교 3학년이 이해하기 쉬운 표현을 사용해 줘.

중요:
처음부터
'교통의 발달로 생활이 편리해졌다'와 같은 정답을 설명하지 마.

학생들이 이야기를 보면서 차이를 스스로 발견하게 해 줘.

마지막 페이지에서는 이야기를 멈추고 큰 글씨로

“교통수단이 달라지면서
사람들의 생활은 어떻게 달라졌을까요?”

라고 질문하며 끝내 줘.

따뜻하고 재미있는 어린이 그림책 스타일로 만들고,
등장인물의 모습이 페이지마다 일관되게 보이도록 해 줘.

4. 그림동화책 형식 슬라이드 만들기

상황

Notebook 슬라이드를 실제 동화책처럼 만들 때

프롬프트
첨부된 초등학교 3학년 사회 교과서 자료를 바탕으로
수업 도입에 사용할 “그림동화책 형식의 슬라이드”를 만들어 줘.

중요:
이 자료는 일반 발표용 PPT가 아니라,
초등학생에게 보여 주는 짧은 그림동화책이어야 해.
각 슬라이드는 책의 한 페이지처럼 구성하고,
그림이 화면의 중심이 되게 해 줘.

[주제]
교통의 변화로 달라진 사람들의 생활 모습

[대상]
초등학교 3학년

[목적]
학생들이 이야기를 보면서
옛날과 오늘날의 이동 모습을 자연스럽게 비교하고,
마지막에 탐구 질문에 대해 생각하게 만드는
수업 도입용 그림동화책을 만들어 줘.

[형식]
- 총 7~8장
- 각 슬라이드는 그림동화책의 한 페이지처럼 구성
- 각 슬라이드의 글은 최대 1~2문장
- 긴 설명문, 목록, 정리 문장 금지
- 교과 개념을 직접 설명하지 말고 이야기와 장면으로 보여 줄 것
- 따뜻하고 흥미로운 어린이 그림책 분위기
- 등장인물의 외모와 분위기는 슬라이드마다 일관되게 유지

[등장인물]
- 옛날에 사는 어린이 1명
- 오늘날에 사는 어린이 1명

[이야기 흐름]
1장: 표지 또는 도입 장면
- 옛날 어린이와 오늘날 어린이가 각각 길을 떠나려는 장면
- 제목 느낌이 나게 구성
- 학생이 “어? 둘 다 어디 가는 거지?” 하고 궁금해지게

2장: 옛날 어린이의 출발
- 먼 곳으로 가기 위해 길을 떠나는 모습
- 이동이 쉽지 않아 보이게 표현

3장: 옛날 어린이의 긴 여행
- 배나 말 등 교과서에 나온 옛날의 이동 모습을 바탕으로
  시간이 오래 걸리는 여행 장면

4장: 오늘날 어린이의 출발
- 같은 목적지로 떠나는 오늘날 어린이의 모습
- 기차나 오늘날 교통수단을 이용하는 장면

5장: 오늘날 어린이의 빠른 이동
- 비교적 빠르고 편리하게 이동하는 모습
- 옛날과 차이가 느껴지게 표현

6장: 두 여행의 비교 장면
- 옛날 어린이와 오늘날 어린이의 이동 모습을 한 장면 안에서 비교
- 설명보다 그림으로 차이가 보이게 해 줘

7장: 생활 모습의 변화가 드러나는 장면
- 교통의 변화로 사람들이 먼 곳을 오가고,
  물건을 주고받고,
  다른 지역과 이어지는 생활 모습을
  교과서 내용에 맞게 간단히 보여 줘
- 여기서도 정답을 직접 설명하지 말 것

8장: 마지막 질문
- 정답, 요약, 해설 없이
  “교통의 변화로 사람들의 생활 모습은 어떻게 달라졌을까요?”
  라는 질문만 크게 제시하며 끝내 줘
- 그림동화책의 마지막 페이지처럼 여운 있게 마무리

[중요한 제한]
- 첨부한 교과서 자료에 근거할 것
- 교과서에 없는 사실이나 수치를 임의로 추가하지 말 것
- 초등학교 3학년이 이해하기 쉬운 쉬운 말 사용
- 설명문보다 이야기, 장면, 대사 중심
- 각 페이지는 그림이 80%, 글이 20% 정도가 되도록 구성
- 페이지마다 글이 많아지지 않게 할 것
- 마지막까지 정답을 직접 설명하지 말 것

일반 발표자료처럼 만들지 말고,
실제 그림동화책을 한 장씩 넘겨보는 느낌으로 구성해 줘.

7. Short — 질문을 남기는 영상

상황

동기유발 슬라이드 PDF만 선택하고 ‘왜 그럴까?’를 남길 때

프롬프트
선택한 소스는 초등학교 3학년 사회 수업 도입을 위해 만든
동기유발 슬라이드 자료입니다.

이 자료를 바탕으로
초등학생이 흥미롭게 볼 수 있는 짧은 질문형 영상으로 만들어 주세요.

[영상 목적]
이 영상은 교과 내용을 설명하는 강의 영상이 아니라,
학생들이 옛날과 오늘날의 이동 모습을 비교하며
궁금증을 느끼고 수업에 몰입하도록 만드는 동기유발 영상입니다.

[영상 형식]
- Short 형식
- 짧고 몰입감 있게 구성
- 이야기 흐름이 자연스럽게 이어지게 할 것
- 초등학교 3학년이 이해하기 쉬운 한국어 사용
- 따뜻하고 친근한 어린이 동화 분위기
- 설명보다 장면 중심
- 마지막까지 정답을 직접 설명하지 말 것

[영상 흐름]
1. 같은 곳으로 떠나는 두 인물을 짧게 보여 준다.
2. 옛날 어린이의 이동은 오래 걸리고 쉽지 않다는 점을 보여 준다.
3. 오늘날 어린이의 이동은 더 빠르고 편리하다는 점을 보여 준다.
4. 두 이동 모습의 차이가 자연스럽게 느껴지도록 비교한다.
5. 결론이나 정답은 설명하지 않는다.
6. 마지막 화면에서 다음 질문을 크게 제시하며 끝낸다.

[마지막 질문]
“두 사람의 여행은 왜 이렇게 달랐을까요?”
“교통의 변화로 사람들의 생활 모습은 어떻게 달라졌을까요?”

[주의]
- 수업 정답을 먼저 설명하지 말 것
- 요약식 설명보다 짧은 이야기처럼 구성할 것
- 글이 너무 많지 않게 할 것
- 학생이 영상을 본 뒤 바로 이야기하고 싶어지게 만들 것

8. Explainer — 이해를 돕는 영상

상황

동기유발 슬라이드 + 원본 교과서를 함께 사용해 설명형 영상을 만들 때

프롬프트
선택한 소스는 초등학교 3학년 사회 수업 자료입니다.
동기유발 슬라이드의 이야기 흐름을 살리되,
원본 교과서 내용에 근거하여
짧고 이해하기 쉬운 설명형 영상으로 만들어 주세요.

[영상 목적]
이 영상은 학생들이
교통의 변화로 생활 모습이 어떻게 달라졌는지
쉽게 이해하도록 돕는 짧은 설명형 영상입니다.

[영상 형식]
- Explainer 형식
- 초등학교 3학년 수준의 쉬운 한국어 사용
- 설명은 짧고 명확하게
- 장면과 설명이 자연스럽게 연결되게 할 것
- 교과서에 근거한 정확한 내용으로 구성할 것
- 지나치게 길거나 딱딱한 강의처럼 만들지 말 것

[영상 흐름]
1. “같은 곳을 가는데 왜 이렇게 다를까요?”라는 질문으로 시작한다.
2. 옛날 사람들은 이동에 오랜 시간이 걸리고 여러 방법을 이용했다는 점을 보여 준다.
3. 오늘날 사람들은 더 빠르고 편리한 교통수단을 이용한다는 점을 보여 준다.
4. 교통수단의 변화로 먼 곳을 오가고, 물건을 운반하고,
   다른 지역과 교류하는 생활이 달라졌다는 점을 간단히 보여 준다.
5. 마지막에는 핵심 질문을 다시 제시하거나, 짧게 생각해 보게 하며 마무리한다.

[마지막 마무리]
정답을 길게 설명하기보다,
“교통의 변화는 사람들의 생활을 어떻게 바꾸었을까요?”
라는 질문으로 다시 생각하게 해 주세요.

[주의]
- 교과서에 없는 사실은 추가하지 말 것
- 전문 용어를 어렵게 설명하지 말 것
- 한 번 보고 이해할 수 있을 만큼 간결하게 만들 것
- 설명형이지만 이야기의 흐름도 어느 정도 유지할 것

9. 영상 결과 보정 3종

상황

Short/Explainer 결과가 설명적이거나 딱딱하거나 부족할 때

프롬프트
[Short가 너무 설명적일 때]
설명문을 줄이고,
